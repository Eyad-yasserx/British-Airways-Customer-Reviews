# British Airways Customer Reviews Dashboard

## Project Overview

This project uses Tableau to analyze British Airways customer reviews and ratings through an interactive dashboard.

## Project Objectives

* Analyze customer satisfaction and review ratings.
* Compare ratings across different aircraft.
* Explore customer reviews by geographic location.
* Analyze rating trends over time.
* Allow users to explore different metrics using interactive filters and parameters.

## Tools Used

* Tableau
* Data Visualization
* Interactive Dashboards
* Filters and Parameters
* Geographic Maps
* KPI Analysis

## Dashboard Features

* Aircraft-level rating analysis.
* Geographic visualization of customer reviews.
* Monthly rating analysis.
* Summary dashboard.
* Interactive filters for date, traveller type, and seat type.
* Dynamic selection of rating metrics.
